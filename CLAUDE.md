# Shared classroom instructions

Read `AGENTS.md`, then `.agents/skills/aftereffect-wrap/SKILL.md`.
Use that one shared procedure; do not create a second divergent skill.
On Windows, Claude Code runs commands in Git Bash: use the `powershell.exe -NoProfile -Command
"& '.\windows\install.cmd' ..."` form from `AGENTS.md`, and give that command a timeout long
enough for the student to answer the UAC prompt.
